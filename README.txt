WURKS AUTO SALES WEBSITE

Files:
- index.html = page structure and contact details
- styles.css = design
- script.js = vehicle inventory

BEFORE PUBLISHING:
1. In index.html, replace (000) 000-0000 with your business phone number.
2. Replace sales@example.com with your email.
3. Replace the Marketplace # link with your Facebook Marketplace/dealer page link.
4. Confirm the Reno / Sparks location wording.
5. In script.js, delete any vehicles you no longer have and update prices/mileage.
6. Add vehicle photos. The current version intentionally uses image placeholders so no incorrect stock photos appear.

FREE HOSTING OPTIONS:
- GitHub Pages: upload these files to a public GitHub repository, then enable Pages under repository Settings > Pages.
- Cloudflare Pages: create a Pages project and upload/deploy this folder or connect it to GitHub.

A custom .com domain is optional and normally costs money, but the website hosting itself can remain free.
